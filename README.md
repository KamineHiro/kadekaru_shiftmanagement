# かでかるシフト管理アプリ

## 概要
かでかるのシフト提出を効率化するためのWebアプリケーションです。2週間分のシフトを簡単に作成し、フォーマットされた形式でコピーできます。

## デモ
[かでかるシフト管理アプリ](https://kadekaru-shiftmanagement.vercel.app)

## 主な機能
- 2週間分のシフト作成・管理
- ランチシフト（9:00-16:00）のワンクリック入力
- ディナーシフト（17:00-22:00）のワンクリック入力
- フォーマット済みシフト表のクリップボードコピー
- PWA対応（オフライン利用可能）

## 技術スタック
- React
- CSS
- Vercel（デプロイ環境）

## 使用方法
1. 開始日を選択します
2. 各日付のシフトを以下のいずれかの方法で入力：
   - 時間を手動入力
   - 「ランチ」ボタンをクリック（9:00-16:00が自動入力）
   - 「ディナー」ボタンをクリック（17:00-22:00が自動入力）
3. 必要に応じて「クリア」ボタンで入力をリセット
4. 「出力結果をコピー」ボタンでシフト表をコピー

## 開発者向け情報
